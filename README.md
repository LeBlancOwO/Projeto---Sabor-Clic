## 🍰 Sobre o projeto

A **Doce Celebração** apresenta doces, bolos, sobremesas e serviços de buffet para aniversários, festas e outras ocasiões especiais. O site tem visual delicado e responsivo, com atendimento pelo WhatsApp.

## ✨ Funcionalidades

-  Cardápio com lista de produtos e busca
-  Cadastro de novos pratos

-  Layout responsivo (computador, tablet e celular)

## Como baixar e executar

### Requisitos

- [Python 3.10 ou superior](https://www.python.org/downloads/)
- [Git](https://git-scm.com/downloads)

### 1. Baixar o projeto

```bash
git clone <LINK-DO-SEU-REPOSITORIO>
cd Projeto---Sabor-Clic
```

> 💡 Também dá para baixar pelo botão verde **Code › Download ZIP** e extrair a pasta.

### 2. Criar o ambiente virtual

<details>
<summary><b>🐧 Linux / macOS</b></summary>

```bash
python3 -m venv .venv
source .venv/bin/activate
```
</details>

<details>
<summary><b>🪟 Windows (PowerShell)</b></summary>

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```
</details>

Quando o ambiente estiver ativo, aparece `(.venv)` no começo da linha do terminal.

### 3. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 4. Executar

```bash
cd SaborEClic_PY
python run.py
```

### 5. Abrir no navegador

```
http://127.0.0.1:5000
```

Para parar o servidor, aperte `Ctrl + C` no terminal.


## 🛠️ Problemas comuns

<details>
<summary><code>No module named 'flask'</code></summary>

O ambiente virtual não está ativo ou as dependências não foram instaladas. Repita os passos 2 e 3.
</details>

<details>
<summary>O site abre sem estilo (CSS)</summary>

Recarregue com `Ctrl + Shift + R` para limpar o cache do navegador e confira se os arquivos estão em `app/static/css/` e `app/static/js/`.
</details>

<details>
<summary><code>No such file or directory</code></summary>

Confira se você está na pasta `SaborEClic_PY` antes de rodar `python run.py`. No Linux, maiúsculas e minúsculas importam.
</details>
